# Performance Optimization Skill

性能优化技能，优化系统性能和资源利用率。

## 触发条件

当需要优化性能时触发：
- 响应时间过长
- 资源利用率低
- 吞吐量不足

## 功能

### 1. 性能分析
- 瓶颈识别
- 资源分析
- 趋势预测

### 2. 优化策略
- 缓存优化
- 并行处理
- 算法优化

### 3. 实施建议
- 具体优化方案
- 预期收益
- 风险评估

## 输出格式

```json
{
  "success": true,
  "data": {
    "bottlenecks": [{"type": "...", "impact": "..."}],
    "optimizations": [{"type": "...", "expected_gain": "..."}]
  }
}
```
