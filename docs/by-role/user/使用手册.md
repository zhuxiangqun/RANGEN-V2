# 📘 RANGEN 系统使用手册

## 概述

RANGEN 是一个多智能体 AI 研究系统，支持智能路由、知识检索、推理生成等功能。

## 系统架构

```
┌─────────────────────────────────────────────┐
│              用户界面层                       │
│  (浏览器 / API / 命令行)                     │
└─────────────────┬───────────────────────────┘
                  │
┌─────────────────▼───────────────────────────┐
│              API 网关层                      │
│  (FastAPI / 认证 / 限流)                    │
└─────────────────┬───────────────────────────┘
                  │
┌─────────────────▼───────────────────────────┐
│              智能路由层                      │
│  (复杂度判断 / 路径选择)                     │
└─────────────────┬───────────────────────────┘
                  │
    ┌─────────────┼─────────────┐
    ▼             ▼             ▼
┌────────┐  ┌──────────┐  ┌────────────┐
│ 知识库 │  │ 推理引擎 │  │ 多智能体   │
│ 检索   │  │          │  │ 协调       │
└────────┘  └──────────┘  └────────────┘
```

## 快速开始

### 启动服务

```bash
./scripts/start_rangen.sh start
```

### 访问地址

| 服务 | 地址 |
|------|------|
| 统一入口 | http://localhost:8500 |
| 聊天界面 | http://localhost:8501 |
| 管理平台 | http://localhost:8502 |
| API 文档 | http://localhost:8000/docs |

## 核心功能

### 1. 智能对话

通过聊天界面与 AI 助手交互，系统会自动选择最优的执行路径。

**使用方式**：
1. 打开聊天界面：http://localhost:8501
2. 输入问题
3. 查看回答

### 2. API 调用

通过 REST API 集成到其他应用：

```bash
curl -X POST http://localhost:8000/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "什么是机器学习？"}'
```

### 3. Agent 管理

通过管理平台管理 AI Agent：

- 查看 Agent 列表
- 测试 Agent 响应
- 配置 Agent 参数

### 4. 知识检索

系统支持多源检索：
- 知识库（KMS）
- 向量数据库
- Wiki

### 5. 推理生成

复杂问题会触发多步骤推理：
- 步骤分解
- 证据收集
- 答案验证

## 配置

### 环境变量

在 `.env` 文件中配置：

```bash
# API 密钥
DEEPSEEK_API_KEY=your_api_key

# 模型选择
LLM_MODEL=deepseek-reasoner
FAST_LLM_MODEL=deepseek-chat
```

### 配置文件

主配置：`config/rangen_v2.yaml`

## 运维

### 服务管理

```bash
./scripts/start_rangen.sh start   # 启动
./scripts/start_rangen.sh stop    # 停止
./scripts/start_rangen.sh status  # 状态
```

### 日志查看

```bash
tail -f logs/research_system.log
```

### 健康检查

```bash
curl http://localhost:8000/health
```

## 故障处理

### 服务无法启动

1. 检查端口占用：`lsof -i :8000`
2. 查看日志
3. 重启服务

### API 请求失败

1. 检查 API 服务状态
2. 确认 API Key 配置正确
3. 检查网络连接
