# 🚀 RANGEN 快速入门指南

## 🎉 欢迎使用 RANGEN

RANGEN 是一个高度智能化的多智能体研究系统，基于 LangGraph 构建，具备强大的推理能力和多模型路由功能。

## ⚡ 快速启动

### 一键启动（推荐）

```bash
./scripts/start_rangen.sh start
```

这将启动完整的服务系统：
- API 基座 (端口 8000)
- 统一入口 (端口 8500)
- 聊天界面 (端口 8501)
- 管理平台 (端口 8502)
- 治理仪表盘 (端口 8503)
- 设计审查 (端口 8504)

### 启动验证

```bash
curl http://localhost:8000/health
```

## 🎯 三种使用方式

### 方式 1：浏览器界面（最简单）⭐

打开浏览器访问：
- 统一入口：`http://localhost:8500`
- 聊天界面：`http://localhost:8501`
- 管理平台：`http://localhost:8502`
- API 文档：`http://localhost:8000/docs`

**功能特点**：
- ✅ 最直观的界面
- ✅ 实时查看执行状态
- ✅ 无需编程知识

### 方式 2：REST API（适合集成）

API 服务运行在 `http://localhost:8000`

**主要接口**：
| 接口 | 说明 |
|------|------|
| `GET /health` | 健康检查 |
| `POST /api/v1/research` | 执行研究查询 |
| `POST /api/v1/chat` | 对话查询 |

**使用示例**：
```bash
curl -X POST http://localhost:8000/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "什么是人工智能？"}'
```

### 方式 3：命令行操作

使用系统状态命令管理服务：
```bash
./scripts/start_rangen.sh status  # 查看状态
./scripts/start_rangen.sh stop    # 停止服务
```

## 📊 系统功能

### 核心功能

1. **智能路由**：根据查询复杂度自动选择执行路径
   - 简单查询 → 直接知识检索
   - 复杂查询 → 完整推理链
   - 多智能体查询 → 多智能体协调

2. **知识检索**：从多个知识源检索信息
   - 知识库管理系统（KMS）
   - FAISS 向量数据库
   - 自动回退机制

3. **推理引擎**：多步骤推理和答案生成
   - 步骤生成
   - 证据收集
   - 答案验证

4. **多智能体协调**：多个专家智能体协作
   - 任务分解
   - 团队组建
   - 执行协调

### 高级功能

- 检查点恢复：支持工作流状态保存和恢复
- 错误恢复：自动重试和备用路由
- 性能优化：缓存、LLM 批量调用
- 动态配置：支持运行时修改配置

## ⚙️ 配置选项

### 环境变量

```bash
# LLM API 配置
export DEEPSEEK_API_KEY=your_api_key
export DEEPSEEK_BASE_URL=https://api.deepseek.com/v1

# 模型选择
export LLM_MODEL=deepseek-reasoner  # 推理模型
export FAST_LLM_MODEL=deepseek-chat  # 快速模型
```
