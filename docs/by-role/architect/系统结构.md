# RANGEN 系统结构

> 最后更新: 2026-03-22

本文档描述了 RANGEN 系统的核心组件和目录结构。

## 1. 核心架构概览

系统主要由以下部分组成：
1. **Orchestration Layer (`src/orchestration/`)**: 负责工作流编排、执行控制、路由决策
2. **Agents Layer (`src/agents/`)**: 核心智能体组件
3. **Skills Layer (`src/skills/`)**: 可插拔技能系统
4. **Services Layer (`src/services/`)**: 业务服务层
5. **Access Layer (`src/access/`)**: API和UI接入

## 3. 核心入口点

| 入口 | 路径 | 说明 |
|------|------|------|
| 主推理引擎 | `src/orchestration/real_reasoning_engine.py` | 核心推理入口 |
| 主控Agent | `src/agents/chief_agent.py` | 团队协调 |
| 生产工作流 | `src/orchestration/executor/production_workflow.py` | 工作流执行 |
| 统一服务器 | `scripts/start_unified_server.py` | 一键启动 |

## 4. 关键模块

### Orchestration (编排层)
- `real_reasoning_engine.py` - 主推理引擎 (~198KB)
- `production_workflow.py` - 生产级工作流
- `intelligent_router.py` - 智能路由

### Agents (智能体层)
- `chief_agent.py` - 主控Agent
- `core/reasoning_agent.py` - 推理Agent
- `specialized/rag_agent.py` - RAG Agent

### Skills (技能层)
- `runtime/skill_trigger.py` - 技能触发器
- `runtime/learning_skill_trigger.py` - 学习型触发器
- `runtime/hybrid_tool_executor.py` - 混合工具执行器
