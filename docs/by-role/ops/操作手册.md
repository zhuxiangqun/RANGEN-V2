# 📘 RANGEN 系统操作手册

## 概述

本手册提供 RANGEN 系统的实用操作指南，包括启动命令、日常运维和故障处理。

## 服务管理

### 一键启动

```bash
./scripts/start_rangen.sh start
```

这将启动所有服务：
- API 基座 (端口 8000)
- 统一入口 (端口 8500)
- 聊天界面 (端口 8501)
- 管理平台 (端口 8502)
- 治理仪表盘 (端口 8503)
- 设计审查 (端口 8504)

### 常用命令

| 命令 | 说明 |
|------|------|
| `./scripts/start_rangen.sh start` | 启动所有服务 |
| `./scripts/start_rangen.sh stop` | 停止所有服务 |
| `./scripts/start_rangen.sh status` | 查看服务状态 |
| `./scripts/start_rangen.sh restart` | 重启所有服务 |

## 配置管理

### 环境变量

在 `.env` 文件中配置：

```bash
# API 配置
DEEPSEEK_API_KEY=your_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com/v1

# 模型配置
LLM_MODEL=deepseek-reasoner
FAST_LLM_MODEL=deepseek-chat

# 日志级别
RANGEN_LOG_LEVEL=INFO
```

### 配置文件

主配置文件位置：`config/rangen_v2.yaml`

## 日常运维

### 查看日志

```bash
# 查看所有日志
tail -f logs/research_system.log

# 查看 API 日志
tail -f logs/api_server.log
```

### 健康检查

```bash
curl http://localhost:8000/health
```

### 清理缓存

```bash
# 停止服务
./scripts/start_rangen.sh stop

# 清理日志
rm -rf logs/*.log

# 重启服务
./scripts/start_rangen.sh start
```

## 故障处理

### 服务启动失败

1. 检查端口占用：`lsof -i :8000`
2. 查看日志：`tail -f logs/research_system.log`
3. 重启服务：`./scripts/start_rangen.sh restart`

### API 请求失败

1. 检查 API 服务：`curl http://localhost:8000/health`
2. 检查 API Key：`echo $RANGEN_API_KEY`
3. 查看 API 日志

### 前端无法访问

1. 检查端口：`lsof -i :8500`
2. 重启服务：`./scripts/start_rangen.sh stop && ./scripts/start_rangen.sh start`
